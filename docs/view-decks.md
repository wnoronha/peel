# View a deck

Decks are markdown files with `marp: true` in the frontmatter. Each `---` section is one slide. Both side panels start closed so the slides get the full width.

## Move between slides

- Click `←` and `→` in the control bar, or press the arrow keys.
- Press `Home` and `End` for the first and last slide.
- Click a collapsed title strip to jump to it.
- Use the sidebar outline or the headings dropdown in the meta line.

The counter reads `3 / 13`. The control bar sticks below the header, so it never scrolls away. Scrolling by hand updates the counter through scroll-spy.

## Link to a slide

The URL carries the position as `?file=deck-ads-monetization.md&slide=3`. Share it or reload it and the deck opens on that slide. The back button returns to the previous page, never to the previous slide.

## Annotate a slide

Select text or diagram labels inside the open slide, then save a note as usual. Notes on collapsed slides are found through the feedback list, which expands the right slide first.
